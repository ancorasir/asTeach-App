Replace this guidance and the placeholders with your schedule. Keep First Class
and Final Class outside the numbered modules. Add or remove module headings and
class entries as needed; these patterns do not add or number any classes.

Format: use a heading for each module, a bold class number and exact title, then
one schedule bullet. Use two digits for the class number, three-letter weekdays
and months, and local 24-hour times without colons. For a public holiday, omit
unknown times and use `Day Mon DD | Public Holiday`; do not invent a time or venue.
