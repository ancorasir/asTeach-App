# Course workspace

Created from the asTeach App v0.1 One-Page GitBook Course Template by
SONG Chaoyang ([songcy@ieee.org](mailto:songcy@ieee.org)) @ Design and Learning Research Group ([https://AncoraSIR.com](https://AncoraSIR.com)).

Map only `course/` into your chosen restricted GitBook Space. The Home is
[course/README.md](course/README.md); keep hidden configuration and includes.
Keep this file, AGENTS.md and LICENSE outside the GitBook project directory.
The included MIT license covers the template and tooling; your new content
remains yours, subject to the rights and policies that apply to it.

Replace the title in Home and SUMMARY together, set the term description, and
edit the reusable sections directly on Home. All dates, names, requirements,
grading and policies must come from you. Learning Outcomes and Co-Requisite
Courses each have their own reusable resource. Both contain replaceable guidance
and a bullet placeholder, not supplied course requirements. Replace or remove
visible guidance before sharing. Keep private preparation outside this mapped
course folder.

Retain the original App package and matched Docs v0.1.1 guide. The source used
here is identified by the original package's release manifest and checksum.
Set up your repository, GitBook mapping, backups and sharing separately.
Ordinary editing does not require running an initializer or an agent again.
