# Course assistance

Read README.md. Help only with the instructor's requested task. The instructor
owns all course text, dates, names, grading, policies and authored files. Preserve
unknown content and stop on conflicting changes. Ask for missing facts; do not
invent course content, contacts or institutional policies.

Only course/ belongs in this workspace's GitBook mapping. Keep license and setup
instructions outside it. Private notes belong in a separately managed location.
Never rerun a blank template over an existing course, reset ownership or infer
permission to publish, change access or send messages. Ordinary content editing
uses the existing Home and reusable resources; no generator is required.
