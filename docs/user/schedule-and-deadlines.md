# Schedule and Deadlines

Docs v0.1.1 · for App v0.1 · release candidate

Edit Teaching Schedule's existing reusable block. First Class and Final Class
are the opening and closing groups. Between them, use level-three module
headings such as `Module 01: Module Title`. These are formatting placeholders,
not course subjects or generated pages.

Under each group, use a bold `Class ##: Class Title` caption and a schedule
bullet shaped `Day Mon DD, HHMM–HHMM | Location`.

Replace the class number with two digits, the title with your actual title,
the weekday and month with three-letter names, and the times with local 24-hour
times without colons. Use an en dash between start and end times. For a holiday
without a class time, the shape is `Day Mon DD | Public Holiday`; enter only a
holiday that applies to your course.

## Make one schedule change

1. Open the course change request and select the existing Teaching Schedule block.
2. Locate the class caption and its immediately following schedule bullet.
3. Edit the supplied title, date, time or location. Check the weekday against
   your calendar.
4. If adding or removing a class, renumber later captions yourself and inspect
   the opening, module and closing groups.
5. Review, merge and reopen as described in [Save, Check and Share](review-and-sharing.md).

The template does not calculate dates, convert time zones, renumber classes or
generate per-class pages. Changes remain your ordinary headings and bullets.

Use the top-level Teaching Schedule heading for navigation, then scroll to the
module. Deep links to module headings inside reusable content are outside
v0.1's supported scope; native include anchors have not been established.

## Important Deadlines

Edit the separate Important Deadlines reusable block. Use the field shape
`Date, Day, Time: DeadlineEvent`, replacing all fields with your own submission
information. Check consistency with the schedule and grading policy.

There is no default late-submission policy. Add one only when you supply or
request it. Preserve omissions or ambiguities in supplied course material
until you decide them; the template does not resolve policy conflicts.
