# Course Home Reference

Docs v0.1.1 · for App v0.1 · release candidate

The source contains thirteen section headings and thirteen reusable blocks.
Every section has its own reusable resource, including Learning Outcomes and
Co-Requisite Courses with replaceable guidance. The following order is the App v0.1
source contract; native rendering and ownership remain separate acceptance checks.

| Order | Heading | Instructor-supplied content / format |
| --- | --- | --- |
| 1 | Course Description | Introduction in paragraphs. |
| 2 | Teaching Goals | Goals in bullets. |
| 3 | Learning Outcomes | Replace `LearningOutcome` with measurable outcomes as bullets using observable action verbs; keep the reusable block. |
| 4 | Content Summary | Scope and topics in paragraphs. |
| 5 | Assumed Knowledge | Expected prior knowledge in bullets. |
| 6 | Co-Requisite Courses | Replace `CourseCode — CourseTitle` with concurrent course codes and titles; keep the reusable block. Write `None` only when confirmed. |
| 7 | Course Instructor & Teaching Team | Known people and contact details, grouped by role. |
| 8 | Grading Policy | Your components, percentages and Individual/Team designations. |
| 9 | Academic Integrity | Your approved policy in paragraphs. |
| 10 | University Calendar | Your authorized calendar image(s), with alt text and a text equivalent. |
| 11 | Recommended Textbook(s) | Your selected bibliography in bullets. |
| 12 | Teaching Schedule | Manually edited group headings, class captions and schedule bullets. |
| 13 | Important Deadlines | Your dated submission events. |

The literal title is `[CourseCode] CourseName`; the separate plain description
is `Year Season`. Replace those fields with your own information.
Fresh Teacher Home uses Product Docs presentation at default width. Confirm the
candidate's native layout, title and description after import. Historical term
and Student pages also use Docs at default width with ordinary detached content. Their section
set can omit a whole section only for a complete confirmed `None` answer; all
thirteen Teacher inputs remain. See the [term workflow](one-page-course.md).

## Field shapes

For team details, replace the role and person guidance with actual approved
information. Lead Instructor uses `FullName | Title | Email`, with Office
Hours and Office Location beneath it. Teaching Assistant(s) and Supporting
Engineer(s) use nested person bullets. Remove roles and personal details you do
not need to publish; the template does not require those positions to exist.

Grading bullets use `(XX%) Component | Individual/Team`. Replace each field and
check the total yourself. No grading calculation or default weighting is supplied.

A bibliography shape is `(Year) AuthorName, BookTitle (Edition), Publisher.`
Use multiple author names when appropriate and add working reference links.
The template does not choose textbooks for you.

Course guidance is visible content until replaced or removed. It provides
formatting prompts; no people, policies, course dates or sample facts are filled
in automatically. Remove unreplaced guidance before sharing.
